# TomoPhantom.jl

[![Stable](https://img.shields.io/badge/docs-stable-blue.svg)](https://hashimoto-koh.github.io/TomoPhantom.jl/stable/)
[![Dev](https://img.shields.io/badge/docs-dev-blue.svg)](https://hashimoto-koh.github.io/TomoPhantom.jl/dev/)

Julia bindings for the native TomoPhantom C core.

This package provides a Julia-native API for:
- 2D/3D model phantoms
- 2D/3D object phantoms
- 2D analytical sinograms
- 3D analytical projection data

## Documentation

Full documentation, including installation instructions, usage tutorials, and API references, is available here:
